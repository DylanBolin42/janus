## 2026-02-18 - [AI Endpoint HTTPS Enforcement] **漏洞：** Unencrypted HTTP endpoints for remote AI service providers could expose sensitive user prompts and API credentials to Man-in-the-Middle (MitM) eavesdropping or interception. **经验心得：** Remote AI integrations often collect API keys or sensitive user data in settings fields. While local development tools might run on unencrypted loopback hosts (`localhost`, `127.0.0.1`), production remote endpoints must strictly enforce HTTPS protocols to satisfy defense-in-depth principles. **预防措施：** When adding configurable remote endpoint fields in setting providers, validate the URI scheme to ensure HTTPS is enforced for non-loopback hosts before persisting or initiating requests.
