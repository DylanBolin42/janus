## 2026-03-31 - AI Endpoint Transport Security **漏洞：** Unvalidated AI endpoint URLs could allow unencrypted HTTP traffic to remote servers, exposing prompt context and user API tokens to MITM interception. **经验心得：** Remote AI endpoints process sensitive user prompts and credentials, requiring HTTPS; local development hosts (`localhost`, `127.0.0.1`) need an exception for local LLM servers (e.g. Ollama). **预防措施：** Validate endpoint schemes in state notifier before persisting, enforcing HTTPS for non-loopback hosts.
