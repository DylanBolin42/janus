## 2026-08-04 - Liquid Glass Widgets Integration
**Learning:** GlassDialog and GlassToast are available via `liquid_glass_widgets` package which provides modal alerts and notifications following Apple's iOS design. When displaying constructive notifications or critical warnings (such as destructive operations), we should wrap them in visual confirmation dialogs using `GlassDialog.show(...)` rather than letting them happen immediately without user feedback, and show confirmation toasts using `GlassToast.show(...)` to ensure clear state transitions and screen-reader friendliness.
**Action:** Use `GlassDialog.show` with custom destructive action configuration and `GlassToast.show` in sub-settings pages like `storage_setting_page.dart` or other parts of the UI to enhance destructive confirmations.
