## 2025-05-18 - Isolate Database Stream Watcher into ConsumerWidget **经验心得：** In Flutter with Riverpod, watching database stream providers at the page root level causes full page rebuilds (including static 300px headers and complex controls) on every database push. Isolating the stream listener inside a sub-tree `ConsumerWidget` scope confines rebuilds strictly to the list area. **后续行动：** When building stream-driven pages in Flutter, isolate `ref.watch(streamProvider)` inside a fine-grained `ConsumerWidget` to keep heavy parent layouts un-rebuilt.
