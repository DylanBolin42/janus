# Bolt's Performance Journal ⚡

## 2025-02-15 - Granular Consumer Isolation in Carousel List Views **经验心得：** When nesting dynamic content (like a state-dependent task carousel list) inside a heavy parent layout with large static elements (e.g., a 300px header), watching the state at the page level causes the entire page to rebuild on every slide/change. By isolating the dynamic list into a standalone `ConsumerWidget` and using a scoped `Consumer` builder to read the carousel selection, we limit rebuilds strictly to the list, saving massive repaint and layout costs. Additionally, nested list-based scrollables inside an outer vertical `ListView` must use `shrinkWrap: true` and `physics: const NeverScrollableScrollPhysics()` to avoid layout constraint exceptions. **后续行动：** In future pages featuring tab bars, sliders, or carousels with dynamic item lists, always isolate the list viewer from the parent page structure using granular Consumer widgets.
